# AURORA — 기법 해설

## 핵심
숨 쉬는 SaaS 런칭 사이트. 느리게 변형되는 CSS 메쉬 그라데이션(보라·마젠타·
시안·에메랄드)이 반투명 글래스 카드 뒤에서 흐른다 — 이른바 "Linear 시대"의
모습. 시그니처는 살아 있는 그라데이션이지, 포인터 반응(LUMEN NORD의 영역)이
아니다.

## LUMEN NORD와의 구별
LUMEN NORD = 포인터 반응 WebGL 오로라 + 서리 낀 노르딕 패널.
AURORA = 자기 변형 CSS 메쉬 + 떠 있는 글래스 카드 + SaaS 산업.
다른 트리거(환경 대 포인터), 다른 매체(CSS 대 WebGL), 다른 산업.

## 기법
1. **scroll-scrub-pinned** — 고정된 기능 섹션; 글래스 카드가 스크롤 진행도에
   따라 조립되고, 나갈 때 분해된다.
2. **pointer-parallax** — 글래스 카드가 포인터를 향해 미세하게 기운다(3D
   transform, 컴포지터 전용).
3. **char-split-reveal** — 히어로 헤드라인 글자가 한 글자씩 등장한다.

## 접근성
- 동작 감소: 그라데이션이 구성된 프레임에 고정; 카드 정지.
- 자바스크립트 없음: 완전히 읽을 수 있는 SaaS 페이지; 그라데이션 기본 프레임.
- 글래스-위-그라데이션에서 AA 대비 검증.
- 한국어 우선 이중언어.
