# ATELIER — design spec

## Identity
아틀리에 — a high-fashion maison publishing the RESERVE collection as an
editorial lookbook. Pure black/off-white + one rare antique-gold accent.
Oversized Bodoni serif, expensive silence. Distinct from ONDO (single perfume
bottle): ATELIER is a full collection lookbook — the magazine-cover-as-website.

## Distinction from ONDO
ONDO = single product / perfume bottle / canvas refraction.
ATELIER = full collection / lookbook / oversized serif / editorial spread.

## Palette
Black `#0a0a0a`, warm off-white `#f8f6f2`, ink-soft `#6b6660`, antique gold
`#b8945a` (used sparingly — one line, one detail).

## Techniques
1. char-split-reveal — maison masthead letter-by-letter.
2. scroll-scrub-pinned — looks crossfade like turning pages.
3. clip-path-reveal — editorial hairline wipes.

## Accessibility
Reduced motion: static editorial. No-JS: fully readable lookbook. AA contrast.
Korean-first bilingual.
