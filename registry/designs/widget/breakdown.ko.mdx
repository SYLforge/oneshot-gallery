# WIDGET — 기법 해설

## 핵심
비전OS 공간 글래스 스타일의 생산성 앱 대시보드. 깊이 그라데이션 위에 떠 있는
반투명 위젯. 한지슬레이트가 단일 전자잉크 기기가 분해되는 것이라면, 위젯은
깊이 속에 떠 있는 글래스 대시보드 위젯의 별자리다. 순수 코드, 이미지 없음.

## 기법
1. **pointer-parallax** — 위젯이 서로 다른 깊이에서 포인터를 향해 기운다(하나의
   pointermove 리스너가 쓰는 CSS 커스텀 프로퍼티 --widget-px/py로 구동되는 3D
   transform).
2. **flip-layout** — 아침/집중 모드 토글이 위젯 그리드를 재배열한다(data-mode
   속성 + CSS grid로 구현 — 측정된 FLIP과 같은 UX 의도, 더 단순하고 신뢰 가능).
3. **clip-path-reveal** — 위젯이 스크롤 시 부드러운 clip-path로 등장.

## 접근성
동작 감소: 위젯 정지, 시차 기울임 없음. 자바스크립트 없음: 모든 위젯이 보이는
완전히 읽기 가능한 대시보드. 글래스 표면에서 AA 대비. 한국어 우선 이중언어.
