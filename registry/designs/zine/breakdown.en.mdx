# 잡지 ZINE — breakdown

## The hook

A small Hongdae press prints a thousand two-color stapled copies of a
zine every month, and the page is one of those issues. The masthead is a
poster, the credits run on a scrolling band, the editor's note is set in
dense multi-column newsprint with a highlighter drop cap and pull quote,
and a grid of six halftone-photo features wipe in with hard clip-path
cuts. The whole thing reads like it was photocopied at 4am and stapled by
hand — and that is the point. In a family with a quiet literary journal
(YEOBAEK), this is the loud sibling: where that entry spends emphasis as
whitespace, this one spends it as density.

The design bet: the *same* editorial-serif family can hold two opposite
magazines. YEOBAEK is air; ZINE is ink. The shared DNA is the
bilingual KO-first essay, the column rule, the folio, the drop cap —
executed at opposite emotional registers.

## Art direction

Everything happens against newsprint cream (`#f4f0e6`). Ink (`#1a1a1a`,
14.6:1) does all the speaking — body text, headlines, the halftone dots,
the masthead. There are two accents, used as instruments: highlighter
yellow (`#fff44f`) is **decorative only** — a marker pass behind the dek,
the drop cap, and the pull quote's flagged clause, never a text color on
its own (it is 2.3:1 as text; words on yellow stay ink, reading 14.8:1).
Stamp red (`#c1272d`, 5.7:1) is the rubber-stamp register — folios,
kickers, the rotated POSTAGE stamp, the focus ring — large and bold only,
never body.

Two faces, two registers. Oswald — the condensed Latin display — is the
poster voice: the masthead's English ZINE, every kicker, every dek, the
marquee band, the bylines. Noto Serif KR is the structural body face: every
Hangul glyph (the masthead 잡지, the essays, the marginalia) at weight
400/500/700/900, with `word-break: keep-all` and line-height 1.72 so
Korean never breaks mid-word and the serif gets its air. The body stack is
Noto Serif KR first; display elements get Oswald by class.

The texture is geometry, not files. Halftone "photos" are SVG dot fields.
Tape is translucent cream rectangles rotated −32° at the photo corners.
Misregistration is everywhere: photos lean ±1–3°, the stamp tilts −7°,
marginalia sit ±1.4° off-axis, the pull quote −0.6°. No `feTurbulence`, no
image grain — the photocopy energy comes from layering and rotation.

## Technique — the photocopied wipe (clip-path-reveal)

The article grid's six features wipe in with hard clip-path cuts — the
photocopied/diagonal feel the brief names. Each card carries a halftone
"photo" panel whose `clip-path` opens from a closed pre-state to fully
revealed, with the card body fading in one beat later:

```css
/* four direction variants rotate across the grid */
.zine-js .zine-card--clip-ltr .zine-photo { clip-path: inset(0 100% 0 0); }
.zine-js .zine-card--clip-diag .zine-photo {
  clip-path: polygon(0 0, 0 0, 0 100%, 0 100%);
}
.zine-js .zine-card--clip-ltr.is-visible .zine-photo { clip-path: inset(0 0 0 0); }
.zine-js .zine-card--clip-diag.is-visible .zine-photo {
  clip-path: polygon(0 0, 100% 0, 100% 100%, 0 100%);
}
```

The four variants — left-to-right, right-to-left, top-to-bottom, and a
diagonal `polygon()` — are distributed across the six cards so the grid
never wipes in lockstep. An IntersectionObserver flips the `is-visible`
class once per card (the reveal hook), with a 70ms stagger per batch; the
photo wipes in 760ms and the body fades 180ms behind it. Every pre-state is
gated behind `.zine-js`, so with JavaScript off every photo is simply shown.

The "photo" itself is an SVG dot field — a grid of `<circle>` elements
whose radius grows toward a soft radial mask center, so the panel reads as
a newsprint duotone: dense where the picture is dark, sparse where it is
light. Six mask variants (stage, riso, crowd, wall, tape, flyers) feel like
different shots of the same underground, all generated by one function.
Zero raster, zero image payload.

## Technique — the scrolling masthead (marquee)

The credits band runs the zine's production credits (INDEPENDENTLY
PRINTED · TWO-COLOR · 1,000 COPIES LIMITED · NO APOLOGIES …) in Korean +
English on a highlighter-yellow strip between two ink rules. It reverses
with scroll direction and accelerates with scroll velocity — a reader
scrolling fast feels the band skid and accelerate.

```ts
// useMarquee.ts — the hook owns one rAF loop, dt-normalized
vel *= Math.pow(0.94, dt / 16.7);              // bleed velocity out
const target = dir * -1 * (BASE + vel * BOOST); // scroll down → drift left
const k = 1 - Math.pow(0.88, dt / 16.7);
cur += (clamp(target, ±CAP) - cur) * k;
offset = wrap(offset + cur * dt);              // keep in (−w, 0] across 4 groups
track.style.transform = `translate3d(${offset}px, 0, 0)`;
```

Four identical groups tile seamlessly — the `wrap()` keeps the offset in
`(−w, 0]` so the seam is invisible. A ResizeObserver re-measures group
width on viewport change; an IntersectionObserver starts and stops the
loop so an offscreen band costs zero frames. The moving row is
`aria-hidden`; the credits are delivered once in a visually-hidden
paragraph before it. Under `prefers-reduced-motion` the hook returns early
and the band holds still — the static zine reads fine without it.

This is one band, where the project's reference marquee runs two — one
band is enough for a zine masthead, and it keeps the rAF cost to a single
loop.

## Technique — a wordmark in two glyphs (char-split-reveal)

The masthead 잡지 is two glyphs, so the per-glyph split costs two spans. The
`h1` keeps the whole word (and its English gloss) in `aria-label`; the
animated characters are `aria-hidden`, each carrying its index as a custom
property:

```tsx
<h1 className="zine-hero__wordmark" lang="ko"
    aria-label="잡지 — ZINE, the photocopy underground">
  <span className="zine-hero__wordmark-ko" aria-hidden="true">
    {MASTHEAD.map((ch, i) => (
      <span className="zine-hero__ch"
        style={{ "--z-ci": i } as CSSProperties}>{ch}</span>
    ))}
  </span>
  <span className="zine-hero__wordmark-en" aria-hidden="true">ZINE</span>
</h1>
```

CSS staggers a **punk letter-splice** — each glyph lands from
`translateY(0.5em) rotate(−4°)` to rest, opacity 0 → 1:

```css
.zine-js .zine-hero__ch {
  animation: z-letter 540ms var(--z-ease-punk) both;
  animation-delay: calc(90ms + var(--z-ci, 0) * 160ms);
}
@keyframes z-letter {
  from { opacity: 0; transform: translateY(0.5em) rotate(-4deg); }
  to   { opacity: 1; transform: translateY(0) rotate(0); }
}
```

This technique is shared with the editorial-serif sibling (YEOBAEK), which
the brief explicitly allows; the distinction is execution. Where that
entry's masthead rises quietly, ZINE's splices in with a rotational kick —
the punk register. The drop cap deliberately does *not* use the split: it
is a wrapped span glyph on a highlighter swatch, a collage element.

## The drop cap on a marker pass

The opener's cap is a real wrapped `<span>` glyph at 3.6em on a highlighter
swatch, rotated −2° — not CSS `::first-letter`, because the yellow marker
must sit behind only the cap (not the whole first line) and the cap must
rotate as part of the collage. The span is `aria-hidden`; the paragraph's
full Korean text is intact and readable. The same marker pass appears
behind the hero dek and the pull quote's flagged clause, each using
`box-decoration-break: clone` so a multi-line highlight reads as one
continuous stroke — exactly how a real highlighter behaves across a line
break.

## Multi-column newsprint, not a margin rail

The essay runs through true CSS `column-count: 2` at ≥940px with a 1px ink
column rule — the dense newsprint register. This is the opposite choice
from the sibling entry, which keeps a single measured column plus a margin
rail because its pinned plates don't compose with fragmentation contexts.
ZINE has no pinned plates, so CSS columns are free, and the pull quote
sits between the columns with `break-inside: avoid`, reading as a dropped
insert. Korean paragraphs lead at line-height 1.74; the English deks
answer in Oswald 400 at 0.92em, ink-soft — a lighter, condensed reply.

Marginalia — three pinned annotation cards marked with a stamp-red ※ —
live in a 13rem margin rail at ≥1080px and fold beneath the column on
narrow viewports. Each carries a 2px hard offset shadow and a slight
rotation: pinned cards, not floating panels.

## Accessibility notes

- **Reduced motion:** the hero skips its choreography, every reveal is
  present without motion, marginalia sit without sliding, the marquee
  holds still, every clip-path panel opens fully (the photos are shown),
  and the link highlighter is simply present. One composed, static zine.
- **No-JS:** every pre-reveal and clip-pre state is gated behind
  `.zine-js`, added on mount. With JavaScript off the page is a finished
  printed zine — which is exactly what a zine should degrade to.
- **Semantics:** halftone photos are `role="img"` with bilingual labels;
  the split masthead hides its spans behind an `aria-label`; the marquee's
  moving row is `aria-hidden` with the credits delivered in a visually-
  hidden paragraph; the drop-cap span is `aria-hidden` with the paragraph
  text intact; focus is a 2px stamp-red `:focus-visible` ring.
- **Contrast:** ink 14.6:1, ink-soft 8.7:1, stamp 5.7:1 (large/bold only);
  the 2.3:1 highlighter is decorative — text on it is ink (14.8:1).

## Performance notes

- One rAF loop exists (the marquee), alive only while the band intersects a
  generous observer margin; each frame is one `transform` write. The
  reveal observer writes `class` + a `--z-reveal-delay` custom property
  imperatively — no React re-renders on scroll anywhere on the page.
- Everything animated is `transform`, `opacity`, or `clip-path`; the
  photos' rotation is static art direction (set once), not animation.
- Zero raster images, zero dependencies; the heaviest assets are two font
  families, and Hangul subsetting is left to next/font.

## Remix ideas

1. **Music-label discography.** Keep the grid; each card becomes a release
   with a halftone sleeve, and the clip-path wipe direction maps to the
   record's era. The marquee runs catalog numbers; the pull quote becomes
   the one-line review.
2. **Protest-broadside archive.** Same bones, but the cards are historical
   handbills, the marginalia carry sourcing, and the highlighter marks the
   censored passages. The stamp becomes a date stamp; the colophon becomes
   the archive's finding aid.
3. **Riso print shop order form.** The page becomes an interactive order
   spec — color count, paper, run size — with the marquee showing live
   queue position and the clip reveals showing each color layer dropping
   in. The dense grid is the paper stock menu.
