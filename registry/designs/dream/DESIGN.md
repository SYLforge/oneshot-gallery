# DREAM — design spec

## Identity
잠이 드는 집 — a sleep house whose page drifts like the moment before sleep.
Pastel clouds float in layered depth, a pinned descent dissolves them as you
scroll deeper, a soft haze overlays everything. The opposite of SUP's grounded
grass — DREAM is airborne, weightless, pastel.

## Distinction from SUP
SUP = grounded / green / grass / growth / earth.
DREAM = airborne / pastel / clouds / drift / weightless.
Same family, opposite gravity.

## Palette
Lavender `#c8b8e8`, peach `#ffd8c8`, mint `#c8f0e0`, cloud white `#f8f4ff`.
Accent lavender-deep `#a78bd9`. Dark text on pastel for AA.

## Techniques
1. pointer-parallax — cloud layers drift toward pointer.
2. scroll-scrub-pinned — clouds dissolve into sleep.
3. feturbulence-texture — dream haze overlay.

## Accessibility
Reduced motion: clouds static. No-JS: fully readable. AA contrast. Korean-first.
