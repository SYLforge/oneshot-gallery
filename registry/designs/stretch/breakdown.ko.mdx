# 늘어남 — 제작기

## 훅: 가르치는 것을 보여주는 사이트

성수동의 한 요가 스튜디오가, 자기가 가르치는 것을 웹사이트로 그대로
보여준다. 제목이 늘어난다. 표지 워드마크는 처음 떠오를 때 뻗고, 스크롤을
잡고 있으면 자세 시퀀스의 이름이 세로로 길어진다 — 자세 속 몸이 늘어나듯.
그 뒤로 세 개의 옅은 원이 숨을 쉰다. 페이지는 스스로를 한 번도 설명하지
않는다. 한 번 긴 숨을 내쉬듯 굴고, 스튜디오의 전제 — 늘어남, 숨, 고요 — 가
곧 페이지의 움직임 어휘이다.

이 디자인의 도박은 하나다. 키네틱 타이포그래피 패밀리의 두 번째 자리에
웰니스 엔트리를 세우되, 그 첫 엔트리(TYPEWAVE)가 어둡고 에너제틱하고
스트로브라면, 여기서는 그 사진 네거티브를 만든다. 어둠이던 자리에 따뜻한
오프화이트, 가로의 떨림이던 자리에 세로의 뻗음, 비트이던 자리에 12초의
호흡. 두 엔트리는 패밀리를 공유하고 그 외에는 아무것도 공유하지 않으며,
그것이 세 번째 자리의 이유다.

## 아트 디렉션

모든 일은 따뜻한 종이(`#f7f3ec`) 위에서 일어난다. 말하는 것은 잉크
(`#2f2a24`, 12.85:1)이고, 밝은 점토색(`#c97b5a`, 2.94:1)은 디스플레이
전용이다 — 거대한 STRETCH 워드마크의 채움, 숨결 원의 선, 자세를 잇는 긴
레일. 읽어야 하는 점토색은 `clay-deep`(`#a85e3f`, 4.38:1)이 맡는다 —
킥커, 자세 번호, 링크 밑줄, 포커스 링. 세이지(`#8a9a7b`, 2.72:1)는 괘선
전용이고, 읽을 수 있는 세이지(`#5f6f50`, 4.90:1)가 숨 큐를 맡는다. 보조
텍스트(영문 번역, 캡션, 카운트)는 잉크 70% 알파, 합성하면 대략
`#6b6660`, 대비 5.14:1.

세리프 둘이 배역을 나누고, 둘 다 *수직 메트릭*을 위해 골랐다. 본명조
(Noto Serif KR)는 페이지의 모든 한글을 맡는다 — 워드마크 늘어, 자세 이름
산·하늘·나무·숨 — 웨이트 700에 `word-break: keep-all`, 행간 2.0으로.
코모란 가라몬드(Cormorant Garamond)는 로마자로 응답한다. STRETCH, 이탤릭
번역문, 캡션. 두 서체 모두 `transform: scaleY()` 아래에서 우아하게
늘어나도록 긴 어센더와 의도적인 수직 결을 가졌기 때문에, 타이포가
늘어날 때 글꼴이 일그러진 게 아니라 몸이 뻗는 것으로 읽힌다.

## 기법 — 뻗는 타이포 (char-split-reveal)

표지 워드마크와 모든 자세 이름은 글리프 단위의 `aria-hidden` 스팬으로
쪼개지고, 그 뒤에 `aria-label`이 한 단어로 읽어준다. 그래서 애니메이션은
글리프별로, 보조기술은 한 단어로 읽는다.

```tsx
<h1 className="stretch-wordmark" aria-label="STRETCH · 늘어">
  <span className="stretch-wordmark__latin" aria-hidden="true">
    {WORD.map((ch, i) => (
      <span className="stretch-wordmark__ch" style={{ "--st-gi": i }}>{ch}</span>
    ))}
  </span>
  …
</h1>
```

표지는 마운트할 때 딱 한 번 정착한다. 글리프마다 `scaleY 0.78 → 1.06 →
1`로 (팽팽함을 12% 넘겨다가 돌아오는 한 번의 뻗음) 90ms 간격으로 떠오르고,
전부 `.stretch-js` 뒤에 숨겨 서버에서 그려진 표지는 이미 완성된 상태다.
자세 이름은 스크롤에 따라 *계속* 늘어난다 — 그 지점에서 char-split은
키네틱이 된다.

## 기법 — 고정된 시퀀스 (scroll-scrub-pinned)

시그니처다. 키 큰 스페이서(약 300vh)가 한 신을 끝까지 고정하고, 그 안에
네 자세가 겹쌓이며, `--st-scrub`(0→1, useStretchScroll에서 나온다)가
전부를 결정한다. 각 자세는 0.25 너비의 구간을 가지고, 활성 자세는 그
구간의 중심에 스크럽이 가장 가까운 자세다.

```css
/* 가시성: 삼각 감쇠, 구간 중심에서 1, 양옆 0.16 안팎으로 사라짐.
   두 clamp의 min()으로 썼다 — 1 - |s-c|/h와 같지만 abs()(너무 새로운
   함수) 대신 min()/clamp()(2020년부터 널리 지원)만 썼다. */
.stretch-pose {
  opacity: clamp(0,
    min(
      calc((var(--st-scrub) - (var(--st-p0) - 0.035)) * 6.25),
      calc((var(--st-p0) + 0.285 - var(--st-scrub)) * 6.25)
    ), 1);
}
/* 뻗음: 국소 스크럽 = clamp((s - p0)/0.25, 0, 1); scaleY = 1 + 국소·1.8 → 최대 2.8 */
.stretch-glyph {
  transform: scaleY(calc(1 + clamp(0, calc((var(--st-scrub) - var(--st-p0)) * 4), 1) * 1.8));
}
```

기하학은 자바스크립트가 아니라 CSS `calc()` 안에 있다 — 자세별 구간은
`--st-p0`/`--st-p1`로 선언되고, rAF 루프가 쓰는 것은 전역 스크럽 하나뿐이다.
그래서 움직임은 스타일시트에서 들여다볼 수 있고, 국소 스크럽·scaleY
상한·가시성 감쇠 같은 수학이 숨지 않는다. 스크럽 자체는 느린 lerp다 — 반감기
약 5.4 프레임 — 그래서 늘어남이 툭 끊기는 게 아니라 참아 낸 숨처럼 읽힌다.

```ts
// useStretchScroll.ts — 한 번 읽고, 느리게 섞고, 한 번 쓴다
const span = Math.max(rect.height - vh * 0.64, 1);
const raw = (vh * 0.18 - rect.top) / span;
const target = Math.min(1, Math.max(0, raw));
value += (target - value) * (1 - Math.pow(0.88, dt / 16.7));
el.style.setProperty("--st-scrub", value.toFixed(4));
```

IntersectionObserver가 루프를 켜고 끄고, `visibilitychange` 리스너가 탭이
숨겨지면 멈춘다 — 화면 밖의 시퀀스는 프레임을 소모하지 않는다. 고정은
네이티브 `position: sticky`이지, 스크립트한 레이아웃이 아니다.

`prefers-reduced-motion` 아래에서, 그리고 자바스크립트 없는 SSR 상태에서는
시퀀스가 평평해진다. 스페이서가 높이를 잃고, 신이 `position: static`이
되고, 네 자세가 모두 가장 긴 상태(scaleY 2.8)에 완전히 쓰인 채로 공기를
두고 흘러내린다 — 네 자세를 품은 차분한 정적 문서. 스크럽 기본값이 1이므로,
폴백은 무언가를 숨기는 열등한 버전이 아니라 완성된 포스터다.

## 기법 — 숨결 배경 (pointer-parallax)

세 개의 동심원이 옅게 겹쳐 있다(종이따뜻 92% α, 점토 7% α, 세이지 6% α).
12초 주기로 숨을 쉬고(scale 1 → 1.06), 포인터를 따라 흐른다. rAF 루프
하나가 스택에 커스텀 프로퍼티 두 개를 쓴다.

```ts
// BreathCircle.tsx — 루프 하나, 포인터 리스너 하나, 쓰기 두 번
const onPointer = (e: PointerEvent) => {
  tx = ((e.clientX / window.innerWidth) - 0.5) * 2;
  ty = ((e.clientY / window.innerHeight) - 0.5) * 2;
};
const frame = () => {
  cx += (tx - cx) * 0.06;
  cy += (ty - cy) * 0.06;
  el.style.setProperty("--st-px", (cx * 12).toFixed(3));
  el.style.setProperty("--st-py", (cy * 12).toFixed(3));
};
```

각 레이어는 자기만의 `--st-depth`(0.4 / 0.7 / 1.0)로 가중치를 받아 오프셋을
소비한다. 그래서 가장 먼 원이 가장 조금 흐른다 — 루프 셋이 아니라 하나에서
나오는 진짜 깊이다. 패럴랙스는 코포인터(거친 포인터)에서는 아예 켜지지
않고(matchMedia로 걸러낸다), 전체가 `aria-hidden`에 이중언어 `role="img"`
라벨을 단다. 장식이고, 그렇다고 말한다.

모션 축소에서는 12초 키프레임이 사라지고 패럴랙스 훅은 시작조차 하지
않는다 — 원은 멈춰 있고, 그 자리에 있다. 호버에 의존하는 것은 아무것도
없다. 터치 사용자는 숨 쉬는 배경을 그대로 받고, 잃는 것은 없다.

## 호흡의 학문

조용한 일은 호흡의 속도다. 리빌은 760ms(기본값보다 느리게), 관측 배치마다
90ms 간격. 스크럽 lerp는 0.88(갤러리 기본 0.86보다 느리게). 워드마크의
오버슈트는 딱 한 번, 마운트할 때만 12% — 반복되는 바운스가 될 수 없다.
웰니스 페이지에서 반복되는 움직임은 불안으로 읽히기 때문이다. 페이지 전체가
12초마다 한 번 숨을 쉬고, 사이에는 완벽하게 고요하다. 모든 이징 곡선은
느린 들숨과 더 긴 날숨의 변주(`ease-breathe`)이고, 유일한 예외는
중간을 넘어서까지 뻗는 `ease-stretch` — 참아 낸 자세다.

## 접근성 메모

- **모션 축소:** 워드마크는 완전히 떠오르고 채워지고, 표지 괘선은 자라나
  있고, 리빌은 움직임 없이 그 자리에, 숨결 원은 멈춰 있고(사이클도
  패럴랙스도 없이), 고정 시퀀스는 네 자세가 가장 길게 참아 낸 정적 문서로
  평평해진다. 완성된 포스터 하나, 애니메이션은 없다.
- **자바스크립트 없이:** 모든 사전 리빌·사전 뻗음 상태는 마운트할 때
  붙는 `.stretch-js` 뒤에 숨겨진다. 자바스크립트가 꺼져도 페이지는 완성된
  스튜디오 사이트다 — 워드마크는 늘어나 있고, 자세는 가장 긴 상태이고,
  이름은 쓰여 있고, 푸터는 그 자리에 있다.
- **시맨틱:** 쪼개진 워드마크와 자세 이름은 스팬을 `aria-label` 뒤에 숨기고,
  숨결 배경은 이중언어 설명을 단 `role="img"`이며, 자세 카드는
  `aria-label`을 갖고, 포커스는 2px clay-deep `:focus-visible` 링이다.
- **대비:** 잉크 12.85:1, clay-deep 4.38:1, ink-soft 5.14:1, sage-deep
  4.90:1 — 모두 AA 이상. 밝은 점토(2.94:1)와 세이지(2.72:1)는 결코 글자를
  싣지 않는다.

## 성능 메모

- rAF 루프가 둘 있다(자세 스크럽과 숨결 패럴랙스), 각각 자기 대상이 넉넉한
  관측 여백 안에 있을 때만 살아 있고, 매 프레임은 `getBoundingClientRect`
  하나와 커스텀 프로퍼티 한두 번 쓰기다. 둘 다 탭이 숨겨지면 멈춘다.
- 움직이는 것은 모두 `transform`이거나 `opacity`이고, 고정은 네이티브
  sticky지 스크립트한 레이아웃이 아니며, 숨결 키프레임도 transform뿐이다.
- 리빌은 하나의 IntersectionObserver에서 `class`와 `transitionDelay`를
  명령형으로 쓴다 — 스크롤 어디에서도 리액트 리렌더는 일어나지 않는다.
- 이미지도 의존성도 0이고, 가장 무거운 자산은 폰트 패밀리 둘이며, 한글
  서브셋팅은 next/font에 맡긴다. 미디어 예산: 0.

## 리믹스 아이디어

1. **다도 학원.** 고정 뻗음을 그대로 두고, 자세를 다도의 네 박(웨다·시키·
   사베·다이)로 바꾼다. 각 박의 이름이 스크롤을 잡고 있으면 늘어나고, 점토는
   말차색으로, 숨결 원은 김이 된다.
2. **롱폼 리딩 앱.** 고정 시퀀스를 한 편의 시로 바꿔, 각 연을 잡고 있으면
   줄이 늘어난다 — 타이포가 물리적으로 길어져 당신의 읽기를 늦춘다. 레일은
   작품 속 당신의 자리를 표시하며 자란다.
3. **물리치료 클리닉.** 뼈대는 그대로, 임상 팔레트로(종이는 남기고 점토는
   차분한 의료용 틸로). 각 '자세'는 재활 스트레칭이 되어 시간 카운터를
   달고, 스크럽은 환자가 직접 해보기 전에 늘어남을 예행연습하게 한다.
