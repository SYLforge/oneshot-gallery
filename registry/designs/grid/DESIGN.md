# GRID — design spec

## Identity
측정된 형태의 사무소 — a fictional architecture atelier publishing its work as
large-format typographic plates. The grid IS the hero — visible grid lines,
modular proportions, baseline grids shown. Distinct from RASTER (wordmark
width-axis): GRID is the architectural grid system itself.

## Distinction from RASTER
RASTER = wordmark / width-axis / FLIP of letters.
GRID = architecture / visible-grid / plates / measured drawings.

## Palette
White `#fafaf8`, ink `#111111`, one signal red `#e63946` (a single accent
line/detail). Ultra-thin sans. Visible grid lines as decoration.

## Techniques
1. flip-layout — project plates FLIP-rearrange by typology.
2. scroll-scrub-pinned — section-drawing builds line-by-line.
3. char-split-reveal — oversized thin numerals.

## Accessibility
Reduced motion: static plates. No-JS: fully readable portfolio. AA contrast.
Korean-first bilingual.
