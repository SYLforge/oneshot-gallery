# GRID — breakdown

## The hook
A fictional architecture atelier that publishes its work as large-format
typographic plates. The grid IS the hero — visible grid lines, modular
proportions, baseline grids as decoration. Where RASTER is about the wordmark's
width-axis, GRID is about the architectural grid system itself.

## Techniques
1. **flip-layout** — project plates FLIP-rearrange as you filter by typology
   (residential/cultural/urban).
2. **scroll-scrub-pinned** — a pinned section where an architectural
   section-drawing builds line-by-line with scroll.
3. **char-split-reveal** — section numbers/titles in oversized thin numerals.

## Accessibility
Reduced motion: static plates. No-JS: fully readable portfolio. AA contrast.
Korean-first bilingual.
