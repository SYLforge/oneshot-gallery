# GRID — reproducible prompt

## Distilled recipe
A fictional architecture atelier that publishes its work as large-format
typographic plates — projects FLIP-rearrange as you filter by typology, an
architectural section-drawing builds line-by-line on a pinned scroll, and
section numbers set in oversized thin numerals. Distinct from RASTER (the 1st
swiss-typographic): RASTER is about the wordmark's width-axis; GRID is about
the architectural grid system itself — visible grid lines, modular proportions.

## Techniques
1. `flip-layout` — project plates FLIP-rearrange on filter.
2. `scroll-scrub-pinned` — a section-drawing builds line-by-line with scroll.
3. `char-split-reveal` — oversized thin numerals reveal.
