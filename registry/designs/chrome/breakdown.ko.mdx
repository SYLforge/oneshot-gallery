# CHROME — 기법 해설

## 핵심
립글로스를 액체 크롬으로 붓고, 모든 카드를 홀로그래픽 박으로 봉하는 Y2K 뷰티
하우스 — 포인터를 따라 잔물결치는 WebGL 크롬 셰이더. PIXEL이 픽셀 아트 게임
아케이드라면, CHROME은 액체 금속 뷰티로, 같은 retro-y2k 패밀리의 정반대 면이다.

## PIXEL과의 구별
PIXEL = 픽셀 아트 / 아케이드 / 게임 / 도파민 채도.
CHROME = 액체 금속 / 뷰티 / 홀로그래픽 / 크롬 광택.
같은 패밀리, 정반대 산업과 질감.

## 기법
1. **webgl-shader** — 포인터를 따라 잔물결치는 액체 크롬(작은 canvas 셰이더).
2. **pointer-parallax** — 홀로그래필 층이 포인터와 함께 이동(무지개 광택).
3. **char-split-reveal** — 크롬 헤드라인 글자가 금속성 스윕으로 등장.

## 접근성
동작 감소: 크롬 정지. 자바스크립트 없음: 완전히 읽기 가능. AA 대비(크롬 위
어두운 글자 검증). 한국어 우선 이중언어.
