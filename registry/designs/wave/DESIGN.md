# WAVE — design spec

## Identity
파동 — a podcast/music-network analytics dashboard whose signature is a live
ASCII spectrum analyzer. 48 box-character bars driven by a simulated beat.
Where PALE.SIGNAL is poetry/logs and GLITCH is corruption, WAVE is
data-visualization — calm, technical, beautiful data.

## Distinction from PALE.SIGNAL and GLITCH
PALE.SIGNAL = clean phosphor / poetry / logs.
GLITCH = corruption / RGB-split / datamosh.
WAVE = data-viz / spectrum / dashboard / functional.

## Palette
Terminal black `#0a0e0a`, phosphor green `#4ade80`, amber `#fbbf24` (warnings),
soft white `#e8f0e8`. Monospace everything.

## Techniques
1. ascii-render — live spectrum analyzer (box-character bars).
2. typewriter — tagline types itself.
3. marquee — now-playing ticker.

## Accessibility
Reduced motion: spectrum static at composed frame. No-JS: fully readable
dashboard. AA contrast. Korean-first bilingual.
