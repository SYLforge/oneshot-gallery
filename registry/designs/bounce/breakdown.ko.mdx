# 통통 — 제작기

## 훅: 모든 것이 통통

마포 어떤 건물 2층, 동그란 문 하나가 있다. 그 뒤에는 아직 신발
묶는 법을 배우는 아이들을 위해 이야기를 만드는 스튜디오가 있다.
이름은 통통. 고무공이 뛸 때 나는 소리다. 이 페이지는 그 소리를
보이게 만들었다. 페이지 위의 모든 것은 고무다. 아무것도 집어 들지
않는다 — 버튼을 누르면 옆으로 넓적하게 쪼그라들었다가 살짝 오버슈트
하며 제자리로 튕겨 돌아온다. 찔린 걸 좋아하는 것처럼. 제목 글자는
하나씩 튀어 오른다. 그림책 카드는 스크롤해서 닿으면 인사하듯 둥
튀어 나온다. 파스텔 풍선들이 손가락을 향해 둥둥 떠간다. 만지는
걸 좋아하는 페이지, 그리고 튕겨 돌아오는 걸로 그렇게 말한다.

이 디자인의 도박은 하나다. 아이들을 위한 페이지가 부드럃되
달콤하지 않기, 그리고 유리 너머로도 전해지는 탄력을 갖기.
"장난스러움"의 바가 이렇게 쉽게 짜증으로 넘어지는 걸 생각하면
해답은 물리를 진짜로 만드는 것이다. 진짜 고무 도장처럼 딱 한 번
오버슈트하고 가라앉는 스프링. 통통, 둥둥. 한 번 튀는 거지
덜덜 떠는 게 아니다.

## 아트 디렉션

팔레트는 파스텔 크레용 상자 한 개 — 버터, 크림, 하늘, 복숭아, 포도
— 그리고 글씨를 쓸 진한 잉크 하나. 이 팔레트를 읽기 쉽게 지켜 주는
규칙은 취향이 아니라 셈이다. 모든 파스텔은 잉크를 AAA 대비
(8.1:1에서 13.0:1)로 실으니까, 버터 단추나 포도 카드나 복숭아
칩이나 다 똑같이 또렷하다. 텍스트로만 쓰면 실패하는 색이 하나 있다
— 액센트 오렌지 `#ff8a5c`, 모든 파스텔 위에서 1.45~2.32:1. 그래서
바탕 전용으로 강등했다. CTA의 채움색(그 위에 잉크 글자가 5.59:1)이
자리하고, 스프링이 부딪힐 때 드는 홍조다. *글자*로 액센트가
필요한 자리에는 대신 자주 `#7a4fb8`(4.10~5.77:1, AA)이 선다.

부드러움이 곧 질감이다. 그레인도 주사선도 그라디언트도 없다.
대신 깊이를 만드는 건 둘이다. 하나, 모서리를 다 둥글게 — 반경이
12px에서 28px을 거쳐 999px까지 간다. 둘, 잉크 알파를 겹층한 부드러운
오프셋 그림자(`0 3px 0 rgba(.10)`, `0 10px 22px rgba(.14)`) — 고무가
닿는 선명한 접촉선 하나, 그리고 부드러운 그림자 하나. 블러 필터가
아니다. 누를 수 있는 표면마다 3px 잉크 외곽선을 둘러서, 스쿼시할 때
외곽선이 함께 늘어났다 줄어드는 걸 보여 준다.

서체 둘, 둘 다 둥글다. 로마자 모든 글자는 Fredoka, 한글 모든 글자는
Gaegu. 디스플레이 스택이 `Fredoka, Gaegu, sans`라 영어 제목 안의
한글은 마크업 없이 Gaegu로 떨어진다. `:lang(ko)`가 그걸 고정하고,
weight 700을 주고(Gaegu의 손그림 스트로크는 볼드가 있어야 디스플레이
크기에서 읽힌다), 단어가 쪼개지지 않게 하고(`word-break: keep-all`),
한글에 맞는 줄높이를 준다. 워드마크는 Gaegu/자주의 "통통"이
Fredoka/잉크의 "BOUNCE" 위에 있다 — 한글이 큰 줄, 영어가 캡션.
대부분 이중언어 사이트의 반대. 일부러.

## 기법 1 — 스프링 프레스: 고무의 튕김

페이지 위에서 누를 수 있는 모든 것 — 히어로 버튼 둘, 그림책 카드
전부, 푸터의 메일 버튼 —은 같은 동작을 한다. 누르면 스쿼시한다.
넓고 낮게, `scale(1.12, 0.82)`로, 한 프레임 안에. 놓으면 임계
감쇠보다 살짝 못 미치는 스프링이 1을 통과해 약간 오버슈트하며
돌아온다. 그 오버슈트 한 번이 통통이다.

스프링 적분은 반-암시적(semi-implicit) 오일러로 한다. 명시적 오일러는
강성 스프링에서 폭발하지만, 이건 안정적이다:

```ts
// useSpringPress — 프레스 스프링의 한 축
const a = (-k * (pos - goal) - c * vel) / m;  // 훅 법칙 − 감쇠
const nv = vel + a * f;                        // 속도를 먼저 갱신하고
const nx = pos + nv * f;                       // 그 다음 위치
```

프레스 설정(강성 380, 감쇠 14, 질량 1)은 임계 감쇠보다 한 끗
못미치게 했다. 임계면 죽은 채로 가라앉고, 과감쇠면 기어가니까.
딱 한 번 6% 오버슈트하고 내려앉을 만큼만 부족하게. 누르면
`sx=1.12, sy=0.82`(눌리는 고무 도장처럼 넓고 낮게), 놓으면
`sx=1, sy=1`, 같은 스프링이 자연스레 오버슈트하며 데려다 놓는다.
`dt`는 48ms로 묶여 백그라운드 탭이 깨어나도 단추가 페이지를
가로질러 날아가지 않는다.

구조적 결정이 둘 중요하다. 하나, 훅은 `style.transform`(scale +
눌림을 nest하는 작은 translateY)만 쓴다. 핫 패스에 레이아웃은
없다 — 단추를 마구 두드려도 리렌더 0회. 둘, JS 스프링이 덮지
않는 경로에 CSS 대안이 있다. 키보드 `:active`(스프링은 포인터
기반이다)와 모션 최소화 전체 경로 둘 다, `styles.css`에 정의된
발진 없는 정적 `scale(1.08, 0.86)` 눌림을 받는다. 키보드 사용자는
정의된 즉각 응답을 받고, 모션 최소화 사용자는 스스로 움직이지 않는
페이지를 받는다.

이건 BLUNT가 `spring-press`를 다루는 방식과 정반대다. 거기서는
안티-이징으로 태그를 모셨다 — `0ms`로 들어가고 `90ms linear`로
나온다. 브루탈리즘의 고무 도장은 전속력으로 종이를 때리고 거의
같은 속도로 떨어지니까. 여기서는 진짜 스프링으로 모셨다. 통통의
전제 자체가 모든 것이 고무라는 것이고, 고무는 오버슈트하니까.
같은 택소노미 태그, 반대 동작, 둘 다 정직하다.

## 기법 2 — 글자 분할 리빌: 글자가 통통 튀어 오른다

히어로 워드마크와 푸터의 인사말이 글리프 단위로 쪼개져 아래에서
부터 하나씩, 각자 오버슈트하며 튀어 올라온다. 분할은 접근성을
지킨다. 컨테이너가 전체 문장을 `aria-label`로 갖고, 움직이는
span들은 `aria-hidden`이라 헤드라인은 깨끗하게 한 번 읽힌다.

```ts
// useBounceReveal — 글리프별 언더댐핑 스프링, 55ms 지연
spans.forEach((span, idx) => {
  g.triggered = true;
  g.startAt = now + idx * STAGGER_MS;   // 각 글자는 자기 차례를 기다린다
});
// tick 안에서: 글리프마다 translateY(34 → 0) + scale(0.5 → 1) 스프링
```

글리프 설정(320 / 12 / 1)은 버튼 프레스보다 날카롭고 더 언더댐핑이다
— 헤드라인은 크게 착지해야 한다. 각 글리프는 `translateY(34px)
scale(0.5)`(자기 자리 바로 아래, 절반 크기)에서 시작해 제자리로
튄다. 가시성은 훅이 글리프의 차례가 오는 순간 추가하는
클래스(`bounce-glyph--in`)로 통제한다. 그래서 글리프가 튀기 전에
제자리에서 깜빡이는 일이 없다 — 이미 시작 위치에서 보이도록 켜지고,
그 위로 튀어 오른다. 그 리빌 전 숨김 상태 자체도 `.bounce-js`로
게이트돼 있어, 자바스크립트가 없으면 헤드라인은 그냥 완성된 채로
있다.

같은 훅이 그림책 카드를 더 부드러운 설정(220 / 18 / 1)으로 모신다.
각 카드가 `translateY(30px) + scale(0.92)`에서 제자리로 튀어 오르고,
같은 observer 배치로 들어온 카드들은 공유 카운터로 90ms 간격으로
펼쳐진다. IntersectionObserver 하나가 텍스트와 카드 둘 다 처리하고,
rAF 루프는 모든 타겟이 가라앉으면 스스로 멈춘다.

## 기법 3 — 포인터 패럴랙스: 끈에 매달린 풍선

파스텔 SVG 도형들 — 뭉치, 통통 별, 구름, 점 — 이 콘텐츠 뒤에 깊이
3단으로 앉아 포인터를 향해 떠간다. 훅이 필드 루트에
`--bounce-px` / `--bounce-py`(각각 −1…1)를 쓰면, CSS가 레이어별 깊이
인수(먼 쪽 0.04, 가까운 쪽 0.18)를 곱한다. 가까운 도형은 더 많이
따라가고 먼 도형은 거의 안 움직인다.

```ts
// usePointerParallax — 포인터 오프셋을 lerp, 60fps 정규화
const k = DRIFT_LERP * (dt / 16.7);     // 0.06/frame
x += (tx - x) * k;  y += (ty - y) * k;
el.style.setProperty("--bounce-px", x.toFixed(4));
```

lerp는 일부러 느긋하게 — 도형이 쫓아오는 느낌, 끈처럼 딸려오는 게
아니라. 필드 전체가 `aria-hidden`에 `pointer-events: none`이다.
반응하는 장식. 두 가드가 다른 기기에서도 올바르게 만든다. 하나,
`(hover: hover) and (pointer: fine)`일 때만 돌아간다 — 터치에서는
도형이 그냥 둥둥 뜬다. 둘, rAF 루프가 화면 밖(IntersectionObserver)과
탭 숨김(visibilitychange)에서 멈춘다. 모션 최소화 설정에서는 훅이
시작조차 하지 않고, CSS 블록이 모든 레이어의 transform을 `none`으로
고정한다.

포인터가 없어도 필드는 살아 있다. 모든 도형이 서로 소수인 주기
(4.6초~9.8초)로 ±6px 둥둥 뜬다. 주기들이 맞물려 눈에 보이는 루프가
되지 않게. 그 둥둥 뜨는 것이 포인터 패럴랙스 외에 페이지의 유일한
앰비언트 모션이다 — 그것도 모션 최소화에서는 죽는다.

## STICKER와의 구별 (패밀리 상한)

플레이풀 팝의 첫 엔트리인 STICKER는 **잡히는** 것이다. 오브젝트를
움켜 관성과 토크, 가장자리 반발과 함께 던진다. 상호작용은 *당신이
세계에 가하는 것*이다. 통통은 **반응하는** 것이다. 아무것도 끌지
않는다. 버튼을 누르면 그 버튼이 당신에게 튕겨 돌아온다. 카드까지
스크롤하면 인사하듯 둥 튀어 나온다. 손가락을 움직이면 배경이 그쪽으로
떠간다. 여기의 세 기법(`spring-press`, `char-split-reveal`,
`pointer-parallax`)은 모두 반응이다 — 어느 것도 포인터를 캡처하지
않고, 어느 것도 당신이 쥔 오브젝트를 옮기지 않는다. 같은 패밀리
(부드럽고, 장난스럽고, 스프링 모션, 한국어 우선), 반대 자세.
STICKER가 잡는 손이라면, 통통은 튕겨 돌아오는 고무 세계다.

## 모션 수학

- **프레스 스프링 380 / 14 / 1.** 고유 진동수 ω₀ = √(k/m) ≈ 19.5
  rad/s; 감쇠비 ζ = c/(2√(km)) ≈ 0.72 — 임계(1.0)보다 못미쳐 한 번
  오버슈트하고, 0.0보다 훨씬 위라 발진하지 않는다. 약 520ms 안에
  1% 이내로 가라앉는다. 덜덜이가 아니라 통통.
- **글리프 스프링 320 / 12 / 1.** ζ ≈ 0.54 — 더 언더댐핑, 더 크게
  착지, 약 18% 오버슈트, 480ms 안에 수렴. 강성이 더 높아 글리프가
  그림책을 넘기는 스네어 같은 느낌으로 도착한다.
- **카드 스프링 220 / 18 / 1.** ζ ≈ 0.92 — 임계 바로 아래, 거의
  오버슈트하지 않는다, 셋 중 가장 부드럽다. 카드는 부드럽게
  가라앉는다. 튕김은 입장에 있고 착지에 있지 않다.
- **패럴랙스 lerp 0.06/frame.** 반감기 약 11프레임(~185ms) — 도형이
  포인터를 한 박자 뒤따르고, 그게 끈처럼이 아니라 무게감으로 읽힌다.
- **둥둥 뜸 ±6px, 서로 소수 주기 4.6~9.8초.** 주기들의 최소공배수가
  커서 필드가 눈에 보이게 반복되지 않는다.

## 성능 노트

- rAF 루프는 총 두 개(패럴랙스 드리프트, 바운스 리빌)고 둘 다
  스스로 꺼진다. 패럴랙스는 IntersectionObserver + visibility로
  멈추고, 리빌 루프는 모든 글리프와 카드가 가라앉으면 멈춘다.
  가만히 있는 페이지 = 0프레임.
- 움직이는 건 전부 `transform`(scale, translate)에 리빌 게이트용
  `opacity`. 레이아웃/페인트 속성은 아무것도 안 움직인다. 그림자
  스택, 외곽선, 파스텔 채움은 한 번 래스터되는 정적 값이다.
- 리빌 훅은 헤드라인 껍데기를 한 번 렌더링하고 글자 분할은 기존
  DOM에 명령형으로 한다 — 14글자 헤드라인이 분할 후 리렌더 0회다.
- `dt`는 모든 루프에서 48ms로 묶여 백그라운드 탭이 깨어나도 글리프가
  순간이동하거나 단추가 튕겨 나가지 않는다.
- 캔버스 없음, 이미지 없음, 의존성 없음. 가장 무거운 에셋이 구글
  폰트 두 종이다.

## 접근성 노트

- **모션 최소화:** `usePrefersReducedMotion`(`matchMedia` 위의
  `useSyncExternalStore`)이 패럴랙스를 완전히 끄고, CSS 블록이 모든
  도형 레이어의 transform을 `none`으로 고정하며, 둥둥 뜸을 죽이고,
  모든 글리프와 카드를 제자리에서 보이게 하고, 단추/카드 눌림을
  발진 없는 60ms linear 미는 것으로 줄인다. 페이지가 잃는 건 통통뿐,
  숨겨지는 건 없다.
- **No-JS:** 리빌 전 숨김 상태(글리프, 아래 대기 중인 카드)는
  `.bounce-js`로 게이트된다. 없으면 헤드라인은 온전하고 카드는
  제자리에 있고 단추는 평범한 링크로 작동한다. JS 없는 페이지는
  완성된 그림책이다.
- **키보드:** 모든 단추는 진짜 링크/버튼, 카드는 `tabindex="0"`을
  가진 포커스 가능한 `<li>`. 3px 자주 포커스 링(자주 푸터 위엔
  크림)이 아트 디렉된 `:focus-visible`이다. CSS `:active` 규칙이
  키보드 활성화에도 같은 정적 눌림을 준다.
- **겹말 없는 스플릿:** 튀는 글리프들은 `aria-hidden` span이고,
  컨테이너의 `aria-label`이 전체 헤드라인을 실어 스크린 리더가
  "통통 튀는 이야기"를 글리프 단위가 아니라 한 번 읽는다.
- **대비:** 모든 파스텔 위 잉크 8.1~13.0:1(AAA 본문), 잉크-소프트
  4.95:1 이상(AA 본문), 자주 4.10~5.77:1(포도 위 3.60:1 대형 텍스트
  전용 제외 AA 본문), 자주 푸터 위 크림/흰 5.77:1(AA 본문).
  액센트 오렌지는 표면과 도형으로만 존재하고, 결코 텍스트가 아니다.
- **터치:** 포인터 패럴랙스는 파인 포인터 전용이다. 터치 기기는
  둥둥 뜸과 스프링을 받고 부서진 패럴랙스는 받지 않는다. 호버 뒤에
  숨겨진 필수적인 것은 없다.

## 리믹스 아이디어

1. **아이 레시피 사이트.** 스프링은 그대로, 카드를 튀어 나오는
   간식(호떡, 붕어빵, 꿀떡)으로 바꾸고, CTA를 "한 입 먹어보기"로.
   누르면 간식이 스쿼시하고 부스러기가 (SVG로, 스프링으로) 튄다.
2. **어린이집 입학 페이지.** 푸터 인사말이 "함께 뛸까요?"가 되고,
   그림책 그리드가 선생님이 된다 — 각 카드가 인사하듯 튀어 나와
   자기소개를 한다. 자주 푸터에 수업 시간이 든다.
3. **자장가 플레이어.** 책장을 빼고 필드와 스프링을 남긴다. 각 트랙이
   누르면 스쿼시하는 알약 단추이고, 떠 있는 도형들이 음악 템포에
   맞춰 떠간다. 모션 최소화는 필드를 구도 잡힌 모빌로 얼어붙인다.
