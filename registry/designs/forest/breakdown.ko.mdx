# FOREST — 기법 해설

## 핵심
내려갈수록 수관이 어두워지는 숲의 은신처. 실제 그림풍 수관 사진 한 장이
CSS 잎 모양과 feTurbulence 잎무늬 뒤에 걸려, 이곳이 장소로 읽힌다 —
그라디언트가 아니라. organic-nature 패밀리의 세 번째 엔트리로, SUP(수면)와
DREAM(연한 파스텔 안개)과 시각적으로 구별된다.

## 페이지의 구조, 위에서 아래로
흔들리는 수관 아래의 히어로; 하강 — 스크롤 진행도에 따라 어두워지는 sticky
섹션, 깊어짐을 표시하는 세 줄의 한국어(빛이 줄어든다 · 이끼가 늘어난다 ·
숨이 깊어진다); 페이지 전체를 덮는 잎무늬 얼룩 오버레이; 그리고 숲이 숨을
죽이는 어두운 푸터.

## 기법
1. **scroll-scrub-pinned** — 하강. sticky 내부가 `--forest-scrub`(0→1, 동작
   감소 시 보간 생략)를 읽어, 배경과 글자색을 `color-mix`로 합성한다. 더
   스크롤할수록 수관은 더 깊어진다.
2. **feturbulence-texture** — 전체 화면을 덮는 SVG `feTurbulence`
   fractalNoise 패스, 저주파, 잎무늬 얼룩 컬러 매트릭스로 마스킹해
   `mix-blend-mode: multiply`로 올림. 잎 사이로 스며드는 빛이다.
3. **pointer-parallax** — 수관 레이어가 깊이별로 포인터를 향해 흔들린다
   (사진이 가장 많이, 가까운 CSS 모양은 가장 적게), `--drm-px` /
   `--drm-py`로 구동. 순수 입력→스타일 매핑이라 동작 감소 시 레이어는 그냥
   멈춰 선다.

## 수관 사진
멀리 레이어는 생성된 이미지 한 장이다(ComfyUI, Illustrious
bismuthIllustrious_v80, 1536×640). 코드로 그린 잎 뒤에 대기로 읽히도록
42%로 어둡게 하고 채도를 낮췄다 — 래스터 깊이와 벡터 모양의 하이브리드.
출처는 meta.json 참조.

## 접근성
동작 감소: 패럴랙스는 멈추고 하강은 보간 없이 스크롤을 따른다 — 완전하고
정돈된 정지 은신처. 자바스크립트 없음: 모든 줄이 읽기 가능한 정적 페이지.
AA 대비(어두워지는 하강에서도 깊어지는 초록 위의 글자 대비를 유지).
한국어 우선 이중언어.
