# PIXEL — breakdown

## The hook
A retro indie-game studio landing page for a fictional 2003 arcade. The hero
is hand-drawn one CSS `box-shadow` per pixel; CRT scanlines and chromatic
aberration sell the tube. Cheerful and saturated — the dopamine side of Y2K,
distinct from CHROME's liquid-metal beauty and GRADIENT-PLAZA's vaporwave.

## Distinction
- vs CHROME: pixel = pixel-art/arcade/game; chrome = liquid-metal/beauty.
- vs GRADIENT-PLAZA: pixel = saturated/cheerful; vaporwave = mauve/melancholic.

## Techniques
1. **ascii-render** — pixel-art sprites via CSS box-shadow grids (one shadow
   per pixel), idle sprite-cycle.
2. **crt-scanline** — full-page scanline + chromatic-aberration overlay,
   flicker under 3Hz, reduced-motion-off only.
3. **marquee** — scrolling chiptune-credits / high-score ticker.

## Accessibility
Reduced motion: no flicker/scanline animation, static sprites. No-JS: fully
readable. AA contrast. Korean-first bilingual. DungGeunMo + Press Start 2P.
