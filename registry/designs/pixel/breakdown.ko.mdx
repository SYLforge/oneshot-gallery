# PIXEL — 기법 해설

## 핵심
가상의 2003년 아케이드를 위한 레트로 인디 게임 스튜디오 랜딩 페이지. 히어로는
CSS `box-shadow`를 픽셀당 하나씩 손으로 그린다; CRT 주사선과 색수차가 브라운관
을 판다. 쾌활하고 채도 높은 — Y2K의 도파민 면으로, CHROME의 액체 금속 뷰티나
GRADIENT-PLAZA의 베이퍼웨이브와 구별된다.

## 구별
- CHROME 대비: pixel = 픽셀 아크레이드/게임; chrome = 액체 금속/뷰티.
- GRADIENT-PLAZA 대비: pixel = 채도/쾌활; vaporwave = 보라/우울.

## 기법
1. **ascii-render** — CSS box-shadow 격자(픽셀당 한 그림자)로 픽셀 아트 스프라이트,
   대기 중 스프라이트 순환.
2. **crt-scanline** — 전체 주사선 + 색수차 오버레이, 3Hz 미만 깜빡임, 동작 감소
   꺼짐일 때만.
3. **marquee** — 칩튠 크레딧 / 하이스코어 티커.

## 접근성
동작 감소: 깜빡임/주사선 애니메이션 없음, 정지 스프라이트. 자바스크립트 없음:
완전히 읽기 가능. AA 대비. 한국어 우선 이중언어. DungGeunMo + Press Start 2P.
